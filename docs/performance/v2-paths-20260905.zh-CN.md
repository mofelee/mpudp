## 运行时改动

Listener 最多声明 256 条路径，本客户端声明五条。此前 `Controller.New` 按本地
最大值分配，listener 控制与 deadline 循环会扫描 256 个状态，实际却只能使用五个
PathID。构造现在核对导出的合同路径数是否等于不可变两端 profile 的最小值，检查
bootstrap PathID 非零且未越界，然后只分配协商数量的状态。

Bootstrap 编号、认证接收/Join 边界及完整本地 carrier 验证均保留。对称 256/256
仍分配 256 个状态。初始 control credit 仍按完整本地 offer 预留，因为准入发生在
选择对端前；改动不增加字节上限，也不取消预付接收工作区。
