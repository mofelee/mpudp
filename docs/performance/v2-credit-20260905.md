## Change And Deterministic Evidence

After successful FEC decoding, the receiver drops the source shards and
reconstruction workspace. Their reservation previously remained charged while
atomic original admission needed an independent destination buffer. The new
`Lease.ShrinkBytes` returns only obsolete byte obligations, preserving the full
decoded logical backing (including manifest bytes), descriptor capacity and live
group metadata. Source and destination remain separately charged during copying.
Completed original deliveries also return discarded range/link charges while
retaining payload bytes and the lease count, including zero-byte deliveries.

The [authenticated regression](../../internal/sessionv2/credit_progress_test.go)
admits 32 real RS(3+2) groups, then reconstructs a 1400-byte original with only
1000 bytes free during decode. It now delivers before expiry while the other
31 groups retain their credit and original deadlines. Additional tests cover
1/256 descriptors, shared logical backing, failed atomic admission/retry,
expiry, simultaneous source/destination ownership, empty/held delivery handles,
and shrink/transfer/release/Close races. Full product race tests, vet and
independent review passed.

This releases obsolete reservations; actual destination/count exhaustion can
still reject admission. Packet scratch is still reserved before decoding, so
competing internal ownership can prevent a completion packet reaching this fix.
The remote data lacks live receive-credit gauges and cannot establish the exact
remaining internal state. Separate workspace protection and observability follow.

## Network Results

The [preceding deadline comparison](v2-deadlines-20260905.md) is the baseline.
Both runs use five existing 100 Mbit/s paths per direction, 20 ms one-way delay,
one flow in one Session, RS(3+2), a 1200-byte UDP budget and 1400-byte originals.
Only each original's 1360 verified body bytes count. There are three warmup
seconds and 15 steady seconds, one round. Profiles/timing diagnostics are off;
host diagnostics are basic. Both source/runner trees were clean. Local tests
and benchmarks were paused during measurement. No VM/hypervisor settings changed.

Only 5/75 scheduled RTT opportunities finish on time for v2 upload and 1/75
for aggregated upload; null quantiles are not low latency. Aggregated upload

on-time replies. No corrupt or duplicate business frames were counted, and all
local tail drains passed. Local socket attempts do not prove remote receipt.

Aligned 15-second receiver samples record 1,535 / 98,405 / 127,112 dispatcher
ingress drops for upload v1 / v2 / aggregation; the preceding run recorded
0 / 109,408 / 143,802. These are full application ingress-queue rejections,
distinct from scratch-credit errors and kernel socket loss. Download ingress
drops and all delivery-queue drops are zero. This evidence does not establish
that credit pressure is the only remaining cause. Endpoint UDP error counters
show no increase over the 14 complete interior sample intervals; wider network
snapshots show no data-interface link/qdisc drop or error increase.
